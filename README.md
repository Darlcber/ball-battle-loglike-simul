- v2 카드 버전(최신): https://darlcber.github.io/ball-battle-loglike-simul/v2/

폰 크롬에서 열고 ⋮ → "홈 화면에 추가"(또는 "앱 설치")를 하면 가로 전체 화면 앱으로 열려요. v1과 v2는 따로 설치돼요.
PC 크롬·엣지에서는 주소창 오른쪽의 설치 아이콘(⊕)을 누르면 바탕화면 바로가기가 생겨요.
게임 파일만 있는 공개 저장소예요. 개발은 비공개 저장소에서 해요.
